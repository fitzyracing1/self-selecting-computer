Self-Selecting Computer

A computer that chooses every program it runs. Nothing is hard-wired except the discovery and selection kernel.

Goal-driven selection Self-registering programs Internet + Browser HTTP Server GPU-aware 19+ programs

What it is

At every boot the machine senses its environment, discovers every program that has self-registered, scores them against a high-level goal, and loads only the coherent subset that fits its resource budget.

There is no master list of required software. Programs announce their own capabilities, costs, and dependencies. The selector decides the entire software complement.

Capabilities

Self-Selection

Goal + environment scoring. Programs are chosen, never pre-installed.

Internet & Browser

Real HTTP fetch, stateful mini-browser, connectivity probes.

HTTP Server

Live status server on port 8765 with JSON API and HTML dashboard.

GPU Awareness

Detects CUDA, reports devices, runs tensor workloads with CPU fallback.

Self-Extension

Can generate new program files that become discoverable on the next boot.

Interactive Terminal

Live REPL: change goals, re-select, run cycles, inspect scores.

Quick start

$ git clone https://github.com/fitzyracing1/self-selecting-computer.git
$ cd self-selecting-computer
$ python3 main.py --terminal
# or one-shot:
$ python3 main.py -g "connect to the internet and run a server"
